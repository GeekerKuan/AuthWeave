# PCL CE 人工回归清单

优先覆盖三个兼容边界，不必逐一人工测试全部版本：

1. Minecraft 1.21 + Fabric：最旧 UI、会话和 NBT 接口。
2. Minecraft 1.21.5 + NeoForge：新版 NBT 接口与旧 UI 的组合。
3. Minecraft 1.21.9 + Fabric：现代 UI、会话和 Authlib 接口的起点。

每个实例只安装对应版本的 AuthWeave；本模组不需要 Fabric API、Architectury API、Auth Me 或
ViaFabricPlus。可以保留整合包中的其他模组做第二轮冲突测试，但第一轮建议只加载本模组。

## 操作步骤

1. 启动游戏，确认没有缺少前置模组的提示。
2. 进入多人游戏并编辑一个服务器，确认右上角出现中文“登录”按钮。
3. 打开登录方案，依次切换正版、离线、皮肤站模式，确认控件和中文提示完整。
4. 使用自己的测试皮肤站账号选择“登录并保存”，随后进入服务器。
5. 检查自己与其他玩家的皮肤、披风；退出后再次连接，确认无需重新输入密码即可使用已保存令牌。
6. 开启“明文保存密码”，通过全屏警告后保存，完全退出并重启游戏；再次编辑该服务器，确认按钮仍显示
   “开启”且密码框有掩码内容。不要分享这一步生成的 `servers.dat`。
7. 再连接一个设为正版或离线方案的服务器，确认不会沿用上一台服务器的第三方身份。

若失败，只需告知实例文件夹名称、加载器和复现步骤。日志通常位于
`<游戏目录>\versions\<实例名>\logs\latest.log`；不要公开发送密码、访问令牌或未经处理的
`servers.dat`。
